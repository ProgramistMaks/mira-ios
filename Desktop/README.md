# Мира для Windows

Переносимое приложение для Windows 10/11 x64. Распакуйте архив целиком и запустите `Mira.exe`. Микрофон, непрерывный разговор на русском, сценарии и голос Руслан работают с движками из комплекта. В разделе «ИИ» можно скачать языковую модель или подключить свой сервер. Команды «Запиши купить молоко», «Прочитай заметки» и «Фокус на 25 минут» выполняются сразу.

В режиме «Поверх окон» Вита появляется на рабочем столе. Перемещение доступно за ручку под персонажем. Через меню в трее можно пропускать щелчки к приложениям или посадить Виту на край выбранного окна. Для игр используйте оконный режим или режим без рамок. Частота в настройках задаёт верхнюю границу отрисовки. Фактическая частота зависит от монитора, видеокарты и нагрузки.

Редактор команд поддерживает фразы, сочетания клавиш, действия, условия, ожидание и повторы. В «Мастерской» можно обмениваться наборами команд в JSON, подключить MCP-сервер по Streamable HTTP и связать личный Telegram-чат. Данные хранятся в профиле пользователя Windows. Ключи защищаются через системное хранилище Electron.

## Сборка

Из корня репозитория, с Node.js 24 и Python 3.11 или новее:

```sh
npm ci
npm ci --prefix Desktop
npm run check
npm test
node --test Desktop/tests/desktop.test.cjs
npm run build
python Desktop/scripts/package.py
```

Сборщик проверяет SHA-256 дистрибутивов Electron, llama.cpp, Piper и Whisper, голосовых моделей и библиотек Visual C++. Готовый файл — `build/desktop/Mira-Windows-x64.zip`. Повторная сборка использует кэш проверенных загрузок. Справка по условиям использования ресурсов находится в `licenses`. Встроенный голос Руслан использует корпус RUSLAN по CC BY-NC-SA 4.0.

На Windows команда `node Desktop/scripts/smoke.mjs` запускает именно упакованный EXE с временным профилем и проверяет граф команд, голосовой ответ, микрофон и окно VRM. Переменная `MIRA_EVIDENCE` указывает папку для снимков. Проверка в Linux использует Electron той же версии через `MIRA_ELECTRON` и соответствующие исполняемые файлы движков через `MIRA_ENGINE_DIR`.

Пользовательский каталог сообщества — JSON по HTTPS с массивом `packs`. Элемент содержит `name`, `id`, необязательное `detail` и `routines` в формате экспорта редактора. Установка добавляет команды в редактор. Для обращения к MCP из чата напишите «Через НазваниеСервера …». Мира покажет предложенный инструмент и его параметры перед вызовом.

### Вита в игре или 3D-программе

«Модель» → «Игры и VMC» экспортирует текущий VRM. Включите приём VMC в совместимой программе, укажите совпадающий UDP-порт и включите передачу в Мире. Поза, пальцы, моргание и рот передаются на 127.0.0.1 до 30 раз в секунду. Частота вывода самой Миры на дисплей задаётся отдельно. Для Minecraft Java один из совместимых приёмников — мод ArmorStand. Он заменяет модель игрока. Вид от третьего лица позволяет увидеть персонажа.

[Протокол VMC](https://protocol.vmc.info/english.html) · [Мод ArmorStand и поддерживаемые версии игры](https://github.com/TouchController/ArmorStand)

Проверка микрофона использует фиксированную запись «Запиши купить молоко», полученную встроенным голосом Руслан. Она хранится в `tests/fixtures/note-ru.wav` и используется по CC BY-NC-SA 4.0. Тест отдельно синтезирует новую реплику упакованным Piper и воспроизводит ответ средствами приложения.

### Разговор и документы

Разговорный режим сам определяет конец реплики, произносит ответ и снова слушает. Кнопка «Ждать обращения» включает локальное ожидание имени. Попробуйте сказать «Мира, запиши планы» и затем «Жди обращения». Микрофон выключается из окна или через значок в трее. «Запомни, что я предпочитаю чай» добавляет запись в память, доступную в настройках.

В «Настройки → Оформление» доступны сплошной цвет, уютный фон с пятью узорами и «Своё изображение или видео». Кнопка «Загрузить» принимает PNG и JPEG до 12 МБ, MP4 и WebM до 128 МБ. Выбранный файл сохраняется в профиле. Видео повторяется без звука, при переходе с главного экрана воспроизведение приостанавливается. Можно отдельно отключить размытие, добавить круглую подложку под кнопки окна и выбрать действие при закрытии.

При первой ошибке внизу рядом с часами появляется «Журнал ошибок». Он хранит последние 20 сообщений текущего сеанса. Открытие журнала сбрасывает счётчик новых ошибок. У каждой строки есть время и кнопка копирования. «Очистить всё» удаляет записи.

Нижняя панель доступна на всех вкладках. «ИИ» открывает настройки модели и подсвечивается, пока модель готовит ответ. Подсказка показывает результат последнего запроса. «Речь» включает и выключает микрофон. «Голос» включает и выключает озвучку ответов. При выключении озвучки Мира продолжает слушать и отвечать текстом. Выбор озвучки сохраняется после перезапуска.

В разделе «Голос → Библиотека голосов» введите имя, например «Братишкин» или «Джарвис». На карточке указаны автор и язык. Кнопка «Послушать» воспроизводит опубликованный образец. Поиск, избранное и примеры работают без ключа. Для новых ответов выбранным голосом сохраните свой ключ Fish Audio. До подключения ключа Мира сохраняет выбор и продолжает пользоваться текущим голосом.

В настройках можно проверить уровень микрофона, выбрать устройства и разрешить прерывание ответа голосом. После обращения по имени Мира может подождать следующую реплику. Длительность задаётся в секундах. Команда «Посмотри в интернете» запускает поиск из разговора. В разделе «ИИ» можно изменить поведение поиска при недоступности Tavily.

В «Голосе» можно скачать Ирину или задать совместимый сервер с методами OpenAI для распознавания и синтеза речи. Выбор облачного распознавания передаёт реплики этому серверу во время разговора. В чате можно приложить Word DOCX, PDF с текстовым слоем или текстовый файл. Извлечение текста идёт на ПК. Ответ по документу обрабатывает выбранная модель.

В поле разговора нажмите `/` для списка команд. Стрелки перемещают выделение, Tab или Enter выбирают действие. `/summary` составляет резюме, `/todos` извлекает чеклист, `/bullets` превращает текст в список, `/refine` исправляет формулировки, а `/rewrite` перефразирует текст. Команда `/think` показывает настройку разговора. Например, `/think high` сохраняет повышенный уровень для следующих ответов в этом чате. Поддержка параметра зависит от модели.

Скрепка принимает несколько документов, таблиц и изображений. Файлы можно перетащить в поле разговора, изображение можно вставить из буфера. Команда `/screen` добавляет снимок дисплея под курсором для просмотра. Отправка выполняется кнопкой со стрелкой. Для Qwen и Gemma в разделе «ИИ» рядом с установленной моделью можно скачать её модуль изображений. При выборе внешнего сервиса он должен поддерживать зрение. Изображения хранятся в профиле чата в формате JPEG с длинной стороной до 1280 пикселей. Модель получает до четырёх последних изображений в контексте. Из XLSX, XLS и ODS извлекаются отображаемые значения с названиями листов.

Если модель передаёт ответ по частям, текст появляется в чате во время генерации. Кнопка остановки сохраняет полученную часть нового ответа. Кнопки «Изменить» и «Ответить заново» работают для переписки с моделью. Изменение ранней реплики заменяет последующие сообщения после получения нового ответа. При отмене или ошибке сохраняется прежняя переписка.

### Рабочий стол и мастерская

Почта включается через «Рабочий стол → Виджеты → Почта». Для входящих нужен сервер IMAP с TLS, для отправки — SMTP с TLS или STARTTLS. Открытые письма могут храниться на ПК неделю. Вложения к заметкам сохраняются в профиле и остаются доступны после перемещения исходного файла.

В режиме «Редактировать» карточки рабочего стола можно перетаскивать или переставлять стрелками. Кнопка «Виджеты» меняет их видимость. Стрелка на карточке открывает подробный вид. На событие в календаре можно назначить повтор и команду. Событие с адресом видеозвонка открывается сценарием «Ближайшая встреча». Команды создаются голосом, текстом или в редакторе. В разделе «Команды → Настройки» можно добавить базовые сценарии, создать команды для ярлыков меню «Пуск», настроить распознавание фраз с опечатками и задать пределы времени, шагов и повторов. Перевод буфера обмена использует выбранную модель. Для тихого режима, музыки и встреч есть устанавливаемые наборы. Команды закрытия окна и таймера выключения Windows требуют подтверждения на ПК. Пока работает таймер, в трее доступна отмена.

В разделе «Модель» на вкладке «Анимации» можно посмотреть каждый жест. Вкладка «Окно» задаёт высоту и угол экрана для отдельного персонажа. На вкладке «Внешний вид» есть два дополнительных наряда Виты с весами для костей юбки и груди. Выбранный наряд виден в разговоре и поверх окон, сохраняется при экспорте VRM. В «Мастерской» доступны шахматы, кот-компаньон, театр теней и Freedoom. Внутри Миры можно играть с клавиатуры и сохранять игру. Для звука в Windows выберите «Окно со звуком». Две версии игры ведут отдельные сохранения. В театре теней можно открыть своё видео или онлайн-плеер оригинального Bad Apple!!.

Мастерская принимает локальный JSON, каталог по адресу и работы из папки `mira-workshop` выбранного репозитория GitHub. Перед публикацией Мира показывает действия и значения параметров. Токен нужен для записи и для чтения приватного каталога. Приложение хранит ключи в системном защищённом хранилище. Набор может добавить панель, тему, сценарии, настройки моделей, речевых провайдеров и MCP-серверов. Подключение сервисов выполняется отдельной кнопкой у установленного набора.

Пример содержимого файла для кнопки «Импорт набора».

```json
{
  "id": "reader",
  "name": "Читальный зал",
  "routines": [
    {
      "name": "Время читать",
      "blocks": [{ "kind": "focus", "value": "20" }]
    }
  ],
  "contributions": {
    "panel": { "name": "Чтение", "body": "Сессия на 20 минут", "commands": [0] },
    "theme": { "theme": "sage", "accent": "#5c745e", "glass": true },
    "blocks": [{ "name": "Таймер чтения", "command": 0 }]
  }
}
```

Индексы `panel.commands` начинаются с нуля и ссылаются на команды этого набора. В `contributions` также поддерживаются `ai` с полями `base, model`, `speech` с полями `base, sttModel, ttsModel, voice` и `tools` со списком объектов `name, url`.

Массив `blocks` добавляет в конструктор именованные последовательности действий набора. В `triggers` можно указать событие `ready` (запуск приложения), `focusEnd` (окончание фокуса) или `reminder` (напоминание) и индекс `command`. Пользователь включает триггеры в панели установленного расширения. Экспорт и публикация набора сохраняют команды, панель, блоки, тему, настройки сервисов и триггеры.

### Остров, окна виджетов и проекты

В настройках включите «Показывать остров». Нажатие на капсулу раскрывает чат, историю, виджеты и полку. Перетащите файл на остров, чтобы добавить его на полку. Полка хранит ссылки на исходные файлы. История буфера включается отдельно и очищается при выключении.

На рабочем столе у фокуса, задач, заметок и календаря есть выбор «На экране ПК». Отдельное окно можно перетащить за заголовок, закрепить поверх других окон и закрыть. В окне фокуса работает таймер, в списке задач можно отметить выполненное.

В истории чатов создайте проект, укажите инструкции для Миры и выберите рабочую папку в редакторе файлов. Из редактора можно сохранить изменения на диск или приложить текст к разговору. Если файл изменился на диске после открытия, редактор попросит открыть его заново.

Сверка с установщиком и перечень оставшихся различий приведены в [разборе Astra 0.2.7](ASTRA-0.2.7.md).

### Первое открытие Миры

На новом профиле мастер предлагает быструю или подробную настройку. «Завершить» применяет выбранные параметры, «Пропустить» открывает разговор с текущими значениями. Открыть мастер повторно можно из настроек.

На главной кнопка «Вита на главной» переключает сцену с персонажем. «Панель виджетов» открывает карточки справа. Кнопка «+» позволяет приложить файл или заметку, а «/» открывает быстрые действия. «Последний чат» возвращает к разговору с самой свежей репликой, в том числе из другого проекта.

В режиме редактирования рабочего стола потяните нижний правый угол карточки или выберите его клавишей Tab и измените размер стрелками. Кнопка корзины убирает карточку с рабочего стола. Вернуть её можно кнопкой «Добавить виджет».

В расширенном окне заметок есть заголовок, форматирование и закрепление. Текст сохраняется во время ввода. Для новой задачи нажмите плюс на карточке и введите текст. В расширенном окне можно изменить список. Календарь открывает месяц и события выбранного дня, напоминания показывают время, повтор и выключатель для каждой записи.
