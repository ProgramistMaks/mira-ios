# Установка IPA и первый запуск

`Mira-unsigned.ipa` — один пакет для подписи своим сертификатом. Внутри уже
находятся приложение, персонаж, сцена, движок локального ИИ и виджеты. Веса моделей
скачиваются из приложения, поэтому IPA не содержит многогигабайтных GGUF-файлов.

1. Импортируй IPA в свой инструмент подписи. Подпиши основное приложение,
   вложенный `llama.framework` и `PlugIns/MiraWidgets.appex`. Не удаляй расширения.
   Профили и идентификаторы приложения/виджета должны соответствовать сертификату
   и устройству. До подписи этот IPA установить нельзя.
2. Установи подписанный пакет и открой «Мира».
3. Открой «Настройки», оставь режим «На iPhone» и открой каталог локальных моделей.
   Выбери модель с учётом показанной оценки памяти. Для первого теста можно выбрать
   Qwen3.5 4B Q4_K_M; выбранная ранее 9B тоже доступна, но требует больше памяти.
4. Подтверди загрузку и дождись проверки целостности файла. Держи приложение
   открытым: при сворачивании загрузка приостанавливается, затем её можно продолжить.
   После установки модели локальный текстовый разговор не требует API-ключа.
5. Для голосового режима нажми «Разговор голосом», затем «Говорить». Вход в режим
   сам не включает микрофон. После записи проверь реплику и отправь её. Если локальное
   распознавание русского языка недоступно на устройстве, остаётся текстовый ввод.
6. Виджет «Рядом с Мирой» добавляется через системное меню виджетов iPhone.
   Live Activity появляется во время работы, если это разрешено в настройках.

Это инструкция для проверки на устройстве, а не подтверждение качества уровня
референсных роликов. Установка с конкретным сертификатом, работа на физическом
iPhone, расход памяти и фактическая частота кадров проверяются отдельно.

Точный статус сборки и тестов: [VERIFICATION.md](VERIFICATION.md).
